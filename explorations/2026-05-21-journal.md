## 21:49 CEST - Agreed clip semantics for input vs output modules

- Clarified the intended meaning of red-zone metering and clip indicators before making more changes to the 8-channel modules.
- Agreed principle:
  red and clip should mean actual fidelity loss in the hardware-facing audio path, not merely that an internal Rack gain stage is boosting the signal.
- Agreed behavior for input modules:
  clip detection should always follow the incoming hardware sample before any plugin gain/boost
  this is effectively an ADC/full-scale warning
  the existing `PRE/POST` switch can continue to affect the general VU ladder, but not the clip indicator semantics
- Agreed behavior for output modules:
  clip detection should always follow the outgoing hardware sample after plugin gain
  this is effectively a DAC/output full-scale warning
  red-zone metering on output modules should align with that post-gain fidelity-loss point
- Terminology note:
  on output modules the control is naturally thought of as `gain`
  on input modules it is more like digital `level` or `boost`, since there is no analog preamp control before conversion
- Next implementation direction:
  decouple clip detection from the current shared `PRE/POST` meter-tap logic
  keep input clip tied to pre-gain hardware level
  keep output clip tied to post-gain hardware level
